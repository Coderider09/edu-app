# EduApp — образовательная платформа для абитуриентов и школьников (Таджикистан)

Мобильное приложение (Flutter, Android/iOS) + backend (FastAPI). Две ветки на одной платформе:

1. **Абитуриенты** — подготовка к централизованным вступительным экзаменам (ЦВЭ / ИМД, «ММТ») по 5 кластерам — на **официальных заданиях Национального центра тестирования**.
2. **Школьники** — школьная программа 1–11 классов: разделы/четверти → темы → уроки и тесты.

Техническое задание: [`TZ_platforma_podgotovka.md`](TZ_platforma_podgotovka.md).

## Официальные данные НЦТ (ntc.tj)

Структура экзамена и задания взяты с сайта Национального центра тестирования при Президенте РТ:

- **Кластеры и субтесты** — «Справочник абитуриента-2026», таблица 9.2 (компонент А, после 11 класса):

  | № | Кластер | А1 | А2 | А3 | А4 | Время |
  |---|---|---|---|---|---|---|
  | 1 | Естественный и технический | Таджикский язык | Математика | Химия | Физика | 220 мин |
  | 2 | Экономика и география | Таджикский язык | Математика | География | Иностранный язык | 200 мин |
  | 3 | Филология, педагогика и искусство | Таджикский язык | История | Тадж. литература / рус. язык и литература | Иностранный язык | 190 мин |
  | 4 | Обществоведение и право | Таджикский язык | История | Право | Иностранный язык | 190 мин |
  | 5 | Медицина, биология и спорт | Таджикский язык | Биология | Химия | Физика | 220 мин |

- **Формат заданий и оценка** (разделы 10–11 и 14 справочника): выбор 1 из 4 (1 очко), установление соответствия A–D ↔ 1–5 (1 очко за пару, до 4), открытый ответ — натуральное число (2 очка). В субтесте 26 заданий (20 + 4 + 2) или 27 для математики, физики и химии (18 + 2 + 7), по 40 очков. Очки субтестов пересчитываются в баллы, всего до 500; таджикский язык (А1) — максимум 75.
- **Задания** — официальные «Типовые тестовые задания ЦВЭ-2026» с ключами ответов (опубликованы бесплатно: https://ntc.tj/ru/abiturientu/tipovye-testovye-zadaniya.html). По 11 предметам **8 450 заданий** всех трёх типов, по темам, включая «образцы субтестов». Задания с формулами, рисунками и таблицами хранятся картинкой, вырезанной из официального PDF, поэтому формулы не искажаются.

В приложении:
- **Тренировка по темам** официального сборника: предмет → тип задания → тема.
- **«Пробный ЦВЭ»** — полный экзамен своего кластера, каждый раз новый вариант: 4 субтеста с официальным числом заданий каждого типа и официальным временем; результат выдаётся по субтестам и в баллах из 500.
- **«Официальный образец ЦВЭ-2026»** — составлен из образцов субтестов НЦТ.

Банк собирается скриптом `python -m tools.ntc_import`: он скачивает PDF с ntc.tj, разбирает задания и сверяет их с ключами. Ключ применяется к блоку заданий, только если номера совпадают один к одному, иначе блок пропускается. Результат — `backend/data/ntc_bank.json` и картинки в `backend/app/static/ntc/`, база заполняется командой `python -m app.seed`.

> 📦 **Банка заданий и картинок нет в репозитории**: для их распространения нужно разрешение НЦТ. Соберите их локально (скачает ~200 МБ PDF, займёт ~20 минут): `cd backend && pip install -r requirements-dev.txt && python -m tools.ntc_import`, затем перезапустите бэкенд или выполните `python -m app.seed`. Без банка приложение работает с демо-теорией и школьным контентом, а пробный ЦВЭ будет пустым.

> ⚠️ **Перед публикацией приложения**: материалы опубликованы НЦТ бесплатно для подготовки абитуриентов, но для их распространения в стороннем приложении (особенно платном) нужно получить письменное разрешение Центра. У каждого задания в приложении указан источник («НЦТ · типовые задания ЦВЭ-2026 · …»).

## Быстрый старт

### Backend в Docker (рекомендуется)

```bash
cd docker
docker compose up --build
```

- API и Swagger: http://localhost:8080/docs
- Админка: http://localhost:8080/admin — `admin@eduapp.tj` / `admin12345` (поменяйте через `FIRST_SUPERADMIN_*`)

При старте контейнер применяет миграции (`alembic upgrade head`) и заливает демо-контент (`python -m app.seed`; повторный запуск ничего не дублирует).

### Backend локально

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements-dev.txt
copy .env.example .env            # укажите DATABASE_URL, SECRET_KEY
alembic upgrade head
python -m app.seed
uvicorn app.main:app --reload
```

Redis необязателен: без него кэш и ограничение попыток входа работают в памяти процесса.

Тесты и линт: `pytest` и `ruff check .` (тесты используют SQLite, PostgreSQL не нужен).

### Mobile

Платформенные папки (`android/`, `ios/`) в репозиторий не входят — сгенерируйте их один раз:

```bash
cd mobile
flutter create --platforms=android,ios --org tj.eduapp .
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080
```

- `10.0.2.2` — адрес компьютера из Android-эмулятора; для телефона укажите IP компьютера в сети.
- Для HTTP без TLS в разработке добавьте `android:usesCleartextTraffic="true"` в `<application>` файла `android/app/src/main/AndroidManifest.xml`.
- Вход через Google: создайте OAuth-клиенты в Google Cloud, передайте Web client ID через `--dart-define=GOOGLE_SERVER_CLIENT_ID=...`, а все client ID — в `GOOGLE_CLIENT_IDS` на backend.

## Что НЕ сделано и требует решения

- **Собственные задания**: 1090 заданий, сложнее типовых, у каждого решение. По всем 11 предметам есть задания на языке экзамена: математика — 108 (4 полных варианта субтеста), остальные — по 2 полных варианта в формате ЦВЭ. Математика, физика, химия, биология, география, история и право есть и на русском, и на таджикском (420 заданий в переводе, ответы сверены с русскими при сборке). Английский и русский язык и литература — только в исходном виде, таджикский язык и литература — на таджикском. Перед публичным запуском задания должны проверить учителя-предметники (особенно тексты на таджикском и право).
- **Уроки и упражнения**: 118 уроков по всем 11 предметам: конспект, мини-проверка из 3 вопросов и 6 упражнений с разборами (1062 вопроса). Первый урок каждого предмета объясняет устройство субтеста и стратегию. Уроки написаны на языке экзамена: таджикский язык и литература — на таджикском, остальные — на русском. Таджикских версий уроков по остальным предметам пока нет. Перед запуском уроки должны вычитать учителя.
- **Разрешение НЦТ**: перед публикацией получите письменное согласие Центра на использование типовых заданий (см. выше).
- **Офлайн и честность рейтинга**: в скачанных пакетах есть ключи ответов, поэтому технически подготовленный пользователь может их прочитать. Сервер пересчитывает каждый ответ сам, но не может отличить честный ответ от подсмотренного. Если рейтинг станет призовым, считайте его только по онлайн-попыткам. Официальные образцы ЦВЭ (`exam_test`) и «Повторить ошибки» работают только онлайн.
- **Шкала баллов**: очки пересчитываются в баллы линейно (`очки / 40 × максимум субтеста`). Реальная шкала НЦТ нелинейная, отдельная для каждого субтеста и кластера и публикуется после экзамена. Распределение 500 баллов между А2–А4 зависит от специальности; в `app/seed_ntc.py` взяты примеры из таблицы 14.2 справочника.
- **Тесты прошлых лет**: тестовые книжки ЦВЭ 2022–2025 на сайте есть, но ключей к ним на сайте нет (опубликованы ключи только к сессии 2026, а её книжек нет). Поэтому «прошлые годы» заменены официальными образцами ЦВЭ-2026 и пробными вариантами из типовых заданий. Если НЦТ даст ключи, книжки можно добавить через админку (Тесты ЦВЭ → вопросы с `exam_test_id`).
- **Не вошло из банка**: около 30 заданий по русскому языку из вариантов образца, для которых нет ключа. В английском представлен только английский язык: немецкий, французский и арабский НЦТ в типовых заданиях 2026 не публиковал. У таджикского языка нет открытых заданий в сборнике, поэтому в пробном ЦВЭ они заменяются заданиями с выбором ответа.
- **Компонент Б** (после 9 класса) не импортирован — приложение ориентировано на поступление после 11 класса.
- **Школьный контент**: заполнен только демо (2–3 классы).
- **Push-уведомления (FCM)**: backend принимает токены устройств (`POST /profile/me/devices`), но отправку и Firebase в приложении нужно подключить (фаза 3 ТЗ, нужен проект Firebase).
- **Lottie-маскот**: анимации сделаны на встроенных средствах Flutter и пакете `confetti`; Lottie-файлов нет.
- **S3/MinIO**: медиа уроков пока задаются URL-ами (`media_urls`, `image_url`), загрузки файлов через админку нет.
- **Celery**: фоновые задачи не понадобились — рейтинг кэшируется в Redis на 60 с и сбрасывается при завершении теста.
- **Переводы**: таджикские строки интерфейса и названия нужно проверить носителю языка.

## API (кратко)

Полная документация — Swagger `/docs`. Префикс `/api/v1`.

- Auth: `POST /auth/register`, `/auth/login` (форма, email или телефон), `/auth/refresh`, `/auth/oauth/google`
- Онбординг: `POST /profile/role`, `GET /clusters`, `/clusters/{id}`, `/subjects?grade=&cluster_id=`, `/regions`, `/avatars`
- Контент: `GET /subjects/{id}/topics`, `/topics/{id}/lessons`, `/lessons/{id}`, `POST /lessons/{id}/complete`, `GET /topics/{id}/tests`, `/exam-tests?cluster_id=&year=`
- Офлайн: `GET /packs?cluster_id=&grade=` (структура кластеров и версии пакетов), `GET /packs/{subject_id}/download` (ZIP), `POST /sync` (офлайн-попытки, прочитанные уроки, отметки; идемпотентно по `client_id`)
- Тесты: `POST /attempts` (`topic_test | section_test | practice | exam_test | mock_exam | lesson_check | mistakes`), `GET /attempts/{id}`, `POST /attempts/{id}/answer`, `POST /attempts/{id}/finish`, `GET /attempts/{id}/result`, `POST|DELETE /questions/{id}/mark`, `GET /review/questions`
- Профиль: `GET|PATCH /profile/me`, `GET /profile/me/progress`, `/profile/me/achievements`, `/profile/me/history`, `GET /dashboard`, `GET /leaderboard?scope=cluster|region|grade&period=week|all`
- Админ: `POST|PUT|DELETE /admin/{clusters|subjects|topics|lessons|questions|exam-tests}`, `GET /admin/stats`, `POST /admin/users/{id}/ban|unban`
