# EduApp — образовательная платформа для абитуриентов и школьников (Таджикистан)

Мобильное приложение (Flutter, Android/iOS) + backend (FastAPI). Две ветки на одной платформе:

1. **Абитуриенты** — подготовка к централизованным вступительным экзаменам (ЦВЭ / ИМД) по 5 кластерам на **собственных заданиях EduApp** в формате экзамена.
2. **Школьники** — школьная программа 1–11 классов: разделы/четверти → темы → уроки и тесты.

Техническое задание: [`TZ_platforma_podgotovka.md`](TZ_platforma_podgotovka.md).

## Формат экзамена

Приложение повторяет устройство ЦВЭ (компонент А, после 11 класса) по открытому «Справочнику абитуриента-2026»:

| № | Кластер | А1 | А2 | А3 | А4 | Время |
|---|---|---|---|---|---|---|
| 1 | Естественный и технический | Таджикский язык | Математика | Химия | Физика | 220 мин |
| 2 | Экономика и география | Таджикский язык | Математика | География | Иностранный язык | 200 мин |
| 3 | Филология, педагогика и искусство | Таджикский язык | История | Тадж. литература / рус. язык и литература | Иностранный язык | 190 мин |
| 4 | Обществоведение и право | Таджикский язык | История | Право | Иностранный язык | 190 мин |
| 5 | Медицина, биология и спорт | Таджикский язык | Биология | Химия | Физика | 220 мин |

- **Типы заданий и оценка**: выбор 1 из 4 (1 очко), установление соответствия A–D ↔ 1–5 (1 очко за пару, до 4), открытый ответ — натуральное число (2 очка).
- **Субтест**: 26 заданий (20 + 4 + 2) или 27 для математики, физики и химии (18 + 2 + 7), по 40 очков. Очки субтестов пересчитываются в баллы, всего до 500; таджикский язык (А1) — максимум 75.

Структура кластеров и субтестов задана в `backend/app/seed_exam.py` и правится в админке.

## Задания и уроки

Все задания и уроки в приложении написаны командой EduApp.

- **Собственные задания — 1 040** (`backend/data/own/`): 620 уникальных заданий по всем 11 предметам и 420 переводов на таджикский. Все три типа заданий ЦВЭ, у каждого задания есть решение.

  | Предмет | Заданий | Языки |
  |---|---|---|
  | Математика | 108 (4 полных варианта субтеста) | рус + тадж |
  | Физика, химия | по 54 | рус + тадж |
  | География, история | по 52 | рус + тадж |
  | Биология, право | по 50 | рус + тадж |
  | Английский язык | 50 | англ. (с инструкциями на русском) |
  | Русский язык и литература | 50 | рус |
  | Таджикский язык, таджикская литература | по 50 | тадж |

- **Уроки — 118** (`backend/data/lessons/`) по всем 11 предметам: конспект, мини-проверка из 3 вопросов и 6 упражнений с разборами (1 062 вопроса). Первый урок каждого предмета объясняет устройство субтеста и стратегию.
- **Краткая теория и школьное демо** (2–3 классы) — в `backend/app/seed.py`.

Исходники заданий и уроков — Python-модули в `backend/tools/own_bank/` и `backend/tools/lessons/`. Команды `python -m tools.own_bank.build` и `python -m tools.lessons.build` проверяют их (формат, разборы, перевод) и пересобирают JSON; `python -m app.seed` загружает всё в базу.

В приложении:
- **Тренировка по темам**: предмет → раздел → тема.
- **«Пробный ЦВЭ»** — полный экзамен своего кластера, каждый раз новый вариант из собственных заданий: 4 субтеста с нужным числом заданий каждого типа и временем экзамена, каждый субтест на языке экзамена пользователя. Результат — по субтестам и в баллах из 500.
- **Фиксированные тесты** (`exam_test`) — полные варианты с постоянным порядком заданий; создаются в админке.

## Быстрый старт

### Backend в Docker (рекомендуется)

```bash
cd docker
docker compose up --build
```

- API и Swagger: http://localhost:8080/docs
- Админка: http://localhost:8080/admin — `admin@eduapp.tj` / `admin12345` (поменяйте через `FIRST_SUPERADMIN_*`)

При старте контейнер применяет миграции (`alembic upgrade head`) и загружает контент (`python -m app.seed`; повторный запуск ничего не дублирует).

### Backend локально

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements-dev.txt
copy .env.example .env            # укажите DATABASE_URL, SECRET_KEY
alembic upgrade head
python -m app.seed
uvicorn app.main:app --reload
```

Redis необязателен: без него кэш и ограничение попыток входа работают в памяти процесса.

Тесты и линт: `pytest` и `ruff check .` (тесты используют SQLite, PostgreSQL не нужен).

### Mobile

```bash
cd mobile
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080
```

- Адрес backend задаётся при сборке через `API_BASE_URL`; по умолчанию `http://10.0.2.2:8080` — компьютер из Android-эмулятора. Для телефона укажите IP компьютера в сети или адрес сервера.
- Сборка APK: `flutter build apk --release --dart-define=API_BASE_URL=http://<сервер>:8080` → `build/app/outputs/flutter-apk/app-release.apk`. Сейчас release подписывается debug-ключом; для Google Play нужен свой ключ.
- HTTP без TLS разрешён (`usesCleartextTraffic` в `AndroidManifest.xml`); для публичного запуска нужен HTTPS.
- Вход через Google: создайте OAuth-клиенты в Google Cloud, передайте Web client ID через `--dart-define=GOOGLE_SERVER_CLIENT_ID=...`, а все client ID — в `GOOGLE_CLIENT_IDS` на backend.

## Что НЕ сделано и требует решения

- **Проверка заданий учителями**: перед публичным запуском задания и уроки должны вычитать учителя-предметники (особенно тексты на таджикском и право).
- **Объём банка**: по большинству предметов в банке 2 полных варианта субтеста (по математике — 4), поэтому варианты «Пробного ЦВЭ» быстро начнут повторяться. Для регулярной подготовки заданий нужно больше.
- **Открытые задания**: у таджикского языка, таджикской литературы, русского языка и литературы, английского и права нет заданий с открытым ответом. В «Пробном ЦВЭ» они заменяются заданиями с выбором ответа (22 + 4 вместо 20 + 4 + 2).
- **Переводы**: английский, русский язык и литература есть только в исходном виде; таджикские версии уроков есть только у таджикского языка и литературы (остальные уроки на русском).
- **Фиксированные тесты**: полных вариантов с постоянным порядком заданий пока нет — их можно собрать в админке (Тесты ЦВЭ → вопросы с `exam_test_id`).
- **Офлайн и честность рейтинга**: в скачанных пакетах есть ключи ответов, поэтому технически подготовленный пользователь может их прочитать. Сервер пересчитывает каждый ответ сам, но не может отличить честный ответ от подсмотренного. Если рейтинг станет призовым, считайте его только по онлайн-попыткам. Фиксированные тесты (`exam_test`) и «Повторить ошибки» работают только онлайн.
- **Шкала баллов**: очки пересчитываются в баллы линейно (`очки / 40 × максимум субтеста`). Реальная шкала экзамена нелинейная, отдельная для каждого субтеста и кластера и публикуется после экзамена. Распределение 500 баллов между А2–А4 зависит от специальности; в `app/seed_exam.py` взяты примеры из таблицы 14.2 справочника.
- **Компонент Б** (после 9 класса) не реализован — приложение ориентировано на поступление после 11 класса.
- **Школьный контент**: заполнен только демо (2–3 классы).
- **Push-уведомления (FCM)**: backend принимает токены устройств (`POST /profile/me/devices`), но отправку и Firebase в приложении нужно подключить (фаза 3 ТЗ, нужен проект Firebase).
- **Lottie-маскот**: анимации сделаны на встроенных средствах Flutter и пакете `confetti`; Lottie-файлов нет.
- **S3/MinIO**: медиа уроков пока задаются URL-ами (`media_urls`, `image_url`), загрузки файлов через админку нет.
- **Celery**: фоновые задачи не понадобились — рейтинг кэшируется в Redis на 60 с и сбрасывается при завершении теста.
- **Переводы**: таджикские строки интерфейса и названия нужно проверить носителю языка.

## API (кратко)

Полная документация — Swagger `/docs`. Префикс `/api/v1`.

- Auth: `POST /auth/register`, `/auth/login` (форма, email или телефон), `/auth/refresh`, `/auth/oauth/google`
- Онбординг: `POST /profile/role`, `GET /clusters`, `/clusters/{id}`, `/subjects?grade=&cluster_id=`, `/regions`, `/avatars`
- Контент: `GET /subjects/{id}/topics`, `/topics/{id}/lessons`, `/lessons/{id}`, `POST /lessons/{id}/complete`, `GET /topics/{id}/tests`, `/exam-tests?cluster_id=&year=`
- Офлайн: `GET /packs?cluster_id=&grade=` (структура кластеров и версии пакетов), `GET /packs/{subject_id}/download` (ZIP), `POST /sync` (офлайн-попытки, прочитанные уроки, отметки; идемпотентно по `client_id`)
- Тесты: `POST /attempts` (`topic_test | section_test | practice | exam_test | mock_exam | lesson_check | mistakes`), `GET /attempts/{id}`, `POST /attempts/{id}/answer`, `POST /attempts/{id}/finish`, `GET /attempts/{id}/result`, `POST|DELETE /questions/{id}/mark`, `GET /review/questions`
- Профиль: `GET|PATCH /profile/me`, `GET /profile/me/progress`, `/profile/me/achievements`, `/profile/me/history`, `GET /dashboard`, `GET /leaderboard?scope=cluster|region|grade&period=week|all`
- Админ: `POST|PUT|DELETE /admin/{clusters|subjects|topics|lessons|questions|exam-tests}`, `GET /admin/stats`, `POST /admin/users/{id}/ban|unban`
