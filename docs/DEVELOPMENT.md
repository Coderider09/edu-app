### Контент

- Данные: `python -m app.seed` (идемпотентно) — структура ЦВЭ и собственные задания (`app/seed_exam.py`, `data/own/`), уроки (`data/lessons/`), краткая теория, школьное демо. Суперадмин создаётся из `FIRST_SUPERADMIN_EMAIL` / `FIRST_SUPERADMIN_PASSWORD`.
- Контент-менеджера назначает суперадмин: «Пользователи» → поле `admin_role` = `content_manager`.
- Вопросы трёх типов (`question_type`):
  - `single` — `options` (4 варианта), `correct_answer` = `[индекс]` (с нуля);
  - `matching` — `matching_left` (A–D), `options` (1–5), `correct_answer` = индексы вариантов для A..D, например `[2, 0, 4, 1]`;
  - `numeric` — `correct_answer` = `"125"`.

  Для мини-проверки урока заполните `lesson_id`, для фиксированного теста ЦВЭ — `exam_test_id`. Чтобы вопрос попадал в «Пробный ЦВЭ», у него должен быть `subject_id`.
- Субтесты кластеров (A1–A4, максимум баллов, язык для альтернатив) — «Субтесты кластеров» в админке.
- Раздел/четверть — тема без родителя; темы внутри раздела — дочерние (`parent_topic`).

### Уроки и упражнения

- Исходники: `tools/lessons/<предмет>_<язык>.py`. Урок описывается через `L(тема, заголовок, конспект в Markdown, мини-проверка, упражнения)`, вопросы задаются через `s`, `m`, `n` — это те же форматы, что и у заданий ЦВЭ.
- `python -m tools.lessons.build` проверит уроки и пересоберёт `data/lessons/*.json`. У каждого урока должен быть конспект (заголовок `#` и разделы `##`, не короче 600 символов), ровно 3 вопроса мини-проверки и не меньше 5 упражнений. У каждого вопроса нужен разбор. Проверки букв и перевода те же, что у заданий.
- `python -m app.seed` добавит в каждый предмет раздел «Уроки и упражнения»: на каждый урок одна тема. Мини-проверка привязана к уроку, упражнения идут в тест по теме. Загрузка идемпотентна по предмету и языку. Таджикская версия урока (`TRANSLATES`, `TOPICS_TJ`) попадает в ту же тему, что и русская.
- Первый урок каждого предмета объясняет, как устроен субтест и как набрать очки.

### Собственные задания (повышенной сложности)

- Исходники: `tools/own_bank/<предмет>_<язык>.py`. Задания описываются через `S` (выбор ответа, верный вариант первым), `M` (соответствие) и `N` (открытый ответ); у каждого задания обязательно решение.
- После правок выполните `python -m tools.own_bank.build`. Скрипт проверит формат (4 разных варианта; для соответствия 4 пункта и 5 вариантов; ответ, который можно вписать в бланк) и пересоберёт `data/own/*.json`. Эти файлы хранятся в git. Если JSON не пересобран, тест `test_built_json_is_up_to_date` упадёт.
- `python -m app.seed` добавит их в раздел «Задания повышенной сложности» каждого предмета. Добавление идемпотентно по предмету и языку. Задания с `subject_id` попадают и в пробный ЦВЭ.
- Сейчас банки есть по всем 11 предметам (`data/own/<предмет>_<язык>.json`). Тест `test_every_subject_has_full_subtests` проверяет, что в каждом банке целое число (не меньше двух) полных субтестов в формате ЦВЭ.
- При сборке варианты ответа перемешиваются детерминированно, в том числе правый столбец заданий на соответствие.
- Переводы (`<предмет>_tj.py`) объявляют `TRANSLATES` — модуль оригинала — и `TOPICS_TJ` (русское название темы → таджикское). Сборка сверяет с оригиналом каждое задание: тип, сложность, тему, ответ для открытых заданий и заданий на соответствие. Задания перевода попадают в те же темы, у тем появляется таджикское название.
- Для текстов на таджикском сборка ищет буквы других кириллических алфавитов (ќ, њ, ў, а также Ц, Щ, Ы, Ь, которых нет в таджикском алфавите). Во всех банках она ищет слова, где смешаны кириллица и латиница.
- Новый банк: создайте модуль и добавьте его в `SOURCES` в `tools/own_bank/build.py`.

### Офлайн-пакеты

- Пакеты собираются автоматически при первом скачивании (`GET /packs/{subject_id}/download`) в `PACKS_DIR` (по умолчанию `data/packs/`, не в git).
- После изменений через админку кэш сбрасывается сразу. После `python -m app.seed` он сбросится в течение часа, или перезапустите backend.
- Правила проверки и начисления баллов продублированы в `mobile/lib/offline/engine.dart`. Меняя `services/testing.py` или `services/gamification.py`, обновите и его (тесты `mobile/test/offline_engine_test.dart`).

### Настройки игровой механики

`app/services/gamification.py`: `BASE_POINTS`, `STREAK_THRESHOLD`, `STREAK_MULTIPLIER`, `COMPLETION_BONUS`, `LEVELS`, `TOPIC_PASS_ACCURACY`, пересчёт в 500 баллов (`scale_subtest`, `estimate_mmt_score`), достижения `ACHIEVEMENTS_SEED`. Максимум баллов по субтестам — в `app/seed_exam.py` (`CLUSTERS`).

## Mobile

```bash
cd mobile
flutter create --platforms=android,ios --org tj.eduapp .   # один раз
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

- Строки интерфейса: `lib/core/l10n/strings.dart` (ключ → текст для `ru` и `tj`).
- Новый экран: добавьте маршрут в `lib/config/router.dart`; переход оформляется автоматически (`_page`).
- Длительности анимаций задавайте через `motion(ref, ms)`, чтобы они сокращались на слабых устройствах.
